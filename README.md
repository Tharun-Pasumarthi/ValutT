# Vault T

Vault T is a premium, local-only, encrypted vault for Android, designed to keep your most sensitive files private and secure.

## Features
- **Total Privacy**: Offline-only. No cloud, no tracking, no ads.
- **Military-Grade Encryption**: Powered by XChaCha20-Poly1305.
- **Hardware Protection**: Keys stored in Android Keystore.
- **Biometric Security**: Quick and secure access using fingerprints or face unlock.
- **Anti-Forensics**: File names and metadata are encrypted.

Currently in **Phase 1: Foundation**.
